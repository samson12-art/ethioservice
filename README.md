# EthioService

Online service booking platform with Telebirr payment integration.

## Features

- User authentication
- Book doctors, tutors, and services
- Telebirr payment integration
- Real-time account validation
- Dark/Light mode

## Tech Stack

- React.js (Vite)
- Node.js/Express
- MongoDB
- Telebirr API

## Installation

```bash
git clone https://github.com/samson12-art/ethioservice.git
cd ethioservice
cd backend && npm install
cd ../frontend && npm install
```

## Environment Variables

Create `.env` file in `backend/` with required variables.
